# PathForge 项目申报书

## 基本信息
- 项目名称：PathForge
- 项目方向：MoonBit 基础数据结构与算法、图搜索、路径规划工具库
- 项目类型：原创建设项目
- 项目仓库：GitHub / GitLink 同步维护

## 项目简介
PathForge 是一个面向 MoonBit 生态的轻量级图搜索与网格寻路工具库，可用于游戏 AI、地图导航、路径规划、算法教学和 WebAssembly 展示。

项目提供 `Graph`、`Grid`、`Point`、`PathReport` 等基础模型，支持 BFS、双向 BFS、Dijkstra、A*、地形权重、可达性检查和可达节点统计等能力。

## 核心功能范围
- 邻接表图模型
- 二维网格地图建模
- 障碍物设置
- 地形移动代价设置
- 路径搜索算法
- 统一结果返回结构
- MoonBit 单元测试
- README 使用示例
